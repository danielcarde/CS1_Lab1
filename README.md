# Lab 1: A Simple Programming Exercise

This project provides a foundational Java programming exercise with tasks focusing on variable usage, data types, and logical expressions. This was my intro to coding in my first semester of college.

## Highlights
- Practical coding challenges for beginners 
- Introduces fundamental Java concepts 
- Solves problems step-by-step with comments 


## Overview
LabOne is a basic command-line application written in Java that guides you through several programming exercises. The code includes commented areas (marked by `//----------`) with specific instructions for each activity (`Q1`, `Q2`, etc.). Each question addresses distinct concepts, such as variable initialization, data type usage, and constructing logical expressions. By completing these tasks within the provided code structure, you'll solidify your understanding of core programming principles in Java.

## Why This Project
This project helps you:

- **Learn by doing**: Practical exercises reinforce theoretical knowledge.
- **Develop problem-solving skills**:  Concisely address challenges with code.
- **Gain familiarity**: Get comfortable working within a basic Java project structure.

## Installation
1. Make sure you have a Java Development Kit (JDK) installed on your machine: [https://www.oracle.com/java/technologies/downloads/](https://www.oracle.com/java/technologies/downloads/) 
2. Save the `LabOne.java` file to your working directory.

 3. Open a terminal in that directory, then compile the code using: `javac LabOne.java`.

4. Run the compiled code with: `java LabOne`.

## Architecture

- The project consists of a single Java file (`LabOne.java`) containing the main program logic and exercises.
- It follows a simple structure:
    -  `main` function is the entry point.
    - Code for each exercise (e.g., Q1, Q2) is contained within commented sections (`//----------`).
